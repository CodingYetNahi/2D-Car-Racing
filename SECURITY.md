# Security Policy

## Supported Versions

Currently our V1.0.0.1 project is being supported by this policy.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Feel free to report the vulnerability to us by simply starting the conversation in discussion tab.
