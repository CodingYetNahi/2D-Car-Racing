# Racing engine audio source

Runtime playback uses the `f1_rpm_step_2.wav` asset hosted in the public `clhforensics/indygp` repository so the browser receives the audio from a reliable static GitHub host instead of hotlinking OpenGameArt's download endpoint.

The source asset documentation traces this racing-engine loop to OpenGameArt's **racing car engine sound loops** by domasx2, licensed CC0/public domain.

Original licensing page: https://opengameart.org/content/racing-car-engine-sound-loops
